Direct Indexing Setup

Direct Indexing lets you replicate the S&P 500 (RSP equal-weight) by buying individual stocks directly, then harvest tax losses on specific positions. It’s a power-user strategy suited to taxable accounts with $100k+ that want to go beyond ETFs.

Step 1 — Generate your initial portfolio

Brokerage Connections

Automatic portfolio sync via SnapTrade — connects to Schwab, Fidelity, Vanguard, TD Ameritrade, and 12,000+ other institutions.

SnapTrade credentials not configured. Set these environment variables (or add them to your .env file), then restart the app:

Setup steps

  1. Sign up at snaptrade.com and create an application to get your Client ID and Consumer Key.
  2. Install the required packages: 
    pip install snaptrade-python cryptography python-dotenv
  3. Add to your .env file: 
    SNAPTRADE_CLIENT_ID=your_client_id_here
SNAPTRADE_CONSUMER_KEY=your_consumer_key_here
ENCRYPTION_KEY=your_fernet_key_here   # generate below
  4. Generate an encryption key (run once): 
    python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
  5. Restart the app, then come back here to connect your brokerage.

🔒 Never commit your .env file to version control. Credentials are encrypted at rest.

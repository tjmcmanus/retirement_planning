## Step-by-Step Tutorials

### Tutorial 1: Setting Up Your First Plan

**Duration:** 15 minutes

1. **Launch the Application**
   ```bash
   ./run.sh
   ```

2. **Configure Personal Information**
   - Navigate to Configuration page
   - Enter names and birth dates
   - Set retirement ages
   - Save configuration

3. **Add Portfolio Accounts**
   - Go to Portfolio Hub
   - Click "Add Account"
   - Enter account details
   - Save changes

4. **Review Dashboard**
   - Check net worth summary
   - Review asset allocation
   - Verify projections

5. **Run Initial Analysis**
   - Navigate to Strategy tab
   - Review withdrawal plan
   - Check tax projections

### Tutorial 2: Optimizing Roth Conversions

**Duration:** 20 minutes

1. **Understand Current Tax Situation**
   - Review current income
   - Check tax bracket
   - Identify conversion capacity

2. **Run BETR Analysis**
   - Navigate to Advanced Strategies
   - Select BETR Roth Conversion
   - Review recommendations

3. **Evaluate Conversion Scenarios**
   - Compare different amounts
   - Check IRMAA impact
   - Review long-term benefits

4. **Implement Strategy**
   - Update portfolio projections
   - Schedule conversions
   - Monitor tax brackets

### Tutorial 3: Creating a Withdrawal Strategy

**Duration:** 25 minutes

1. **Define Retirement Goals**
   - Set retirement date
   - Determine income needs
   - Identify expense categories

2. **Configure Strategy Parameters**
   - Navigate to Strategy tab
   - Set withdrawal preferences
   - Choose optimization goals

3. **Review 6-Stage Plan**
   - Examine each life stage
   - Understand account sequencing
   - Check tax implications

4. **Run Monte Carlo Simulation**
   - Set simulation parameters
   - Review success probability
   - Analyze risk factors

5. **Refine and Optimize**
   - Adjust spending levels
   - Modify asset allocation
   - Test sensitivity

### Tutorial 4: Portfolio Rebalancing

**Duration:** 15 minutes

1. **Review Current Allocation**
   - Check Portfolio Hub Overview
   - Compare to target allocation
   - Identify drift

2. **Generate Rebalancing Plan**
   - Navigate to Optimization tab
   - Review recommendations
   - Check tax impact

3. **Evaluate Tax Efficiency**
   - Identify tax-loss harvesting
   - Check wash sale rules
   - Optimize transaction order

4. **Implement Changes**
   - Execute recommended trades
   - Update portfolio data
   - Verify new allocation

## Common Workflows

### Monthly Review Workflow

1. **Update Account Balances**
   - Import latest statements
   - Update market values
   - Record contributions

2. **Review Performance**
   - Check returns vs. benchmarks
   - Analyze risk metrics
   - Identify trends

3. **Check Rebalancing Needs**
   - Review allocation drift
   - Evaluate rebalancing triggers
   - Plan tax-efficient trades

4. **Update Projections**
   - Refresh retirement timeline
   - Adjust expense estimates
   - Review goal progress

### Annual Planning Workflow

1. **Year-End Tax Planning**
   - Review tax-loss harvesting
   - Plan Roth conversions
   - Optimize charitable giving
   - Check RMD requirements

2. **Contribution Planning**
   - Maximize 401(k) contributions
   - Fund IRA accounts
   - HSA contributions
   - 529 plan funding

3. **Strategy Review**
   - Update retirement timeline
   - Adjust withdrawal strategy
   - Review Social Security plan
   - Update estate plan

4. **Performance Analysis**
   - Annual return calculation
   - Risk assessment
   - Benchmark comparison
   - Goal tracking

### Pre-Retirement Workflow

1. **Retirement Readiness Check**
   - Calculate retirement number
   - Review income sources
   - Verify healthcare coverage
   - Check Social Security estimates

2. **Transition Planning**
   - Finalize withdrawal strategy
   - Set up income streams
   - Optimize tax situation
   - Review insurance needs

3. **Account Consolidation**
   - Roll over old 401(k)s
   - Consolidate IRAs
   - Simplify account structure
   - Update beneficiaries

4. **Final Optimization**
   - Last-minute Roth conversions
   - Tax-loss harvesting
   - Asset allocation adjustment
   - Emergency fund verification

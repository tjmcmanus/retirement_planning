# UI Component Test Suite

This is a standalone Streamlit app that showcases all available UI components and design options.

## Running the Test App

```bash
streamlit run test_ui_components.py
```

This will open a browser window displaying all the reusable components, including:
- Alert components (success, warning, error, info)
- Metric cards and grids
- Progress indicators and score gauges
- Status badges
- Info cards
- Styled data tables
- Loading states
- Empty states
- Collapsible sections
- Action lists
- Comparison cards
- Theme color palette

Use this as a reference when building new features or pages in the retirement planning application.
